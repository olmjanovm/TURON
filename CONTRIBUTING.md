# Contributing

Thanks for contributing to TURON.

## Development workflow
1. Fork/branch from the default branch.
2. Keep changes small and focused.
3. Do not commit secrets or `.env*` files.
4. Update docs when behavior/config changes.
5. Open a PR with clear scope, validation steps, and follow-ups.

## Local checks before PR
- Run lint for touched apps.
- Run relevant tests (if present).
- Verify critical flows manually.

## Commit style
Use concise, descriptive commit messages and group related changes only.
